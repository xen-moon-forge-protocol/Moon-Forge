# Moon Forge Branding

Visual assets for the Moon Forge Protocol, free to use when writing about or building on the project (MIT, like the code). Please link to the official site and repository, and do not use these assets to make a clone look official.

## Visual direction

- **Colors:** deep space black, ether blue, pulse purple and solar gold.
- **Mood:** cinematic, technical, calm.
- **Tone of copy:** factual. Describe what the program does, its fees and its risks; avoid return promises.

## Trust model (for accurate copy)

The program is upgradeable during the public test period (the architect wallet holds the upgrade authority until it is burned); the oracle that reports EVM burns is off-chain but bounded by the program. Details: [SECURITY.md](../SECURITY.md) and [IMMUTABILITY.md](../IMMUTABILITY.md).
