# Moon Forge Branding

Visual assets for the Moon Forge Protocol, free to use when writing about or building on the project (MIT, like the code). Please link to the official site and repository, and do not use these assets to make a clone look official, to run a "community" or "support" account that is not clearly independent, or to post about the project as someone else.

The images were made with an AI image tool from the project's own prompts and then edited; embedded generator metadata was removed from the published files. No claim of hand-made art is made.

## Visual direction

- **Colors:** deep space black, ether blue, pulse purple and solar gold.
- **Mood:** cinematic, technical, calm.
- **Tone of copy:** factual. Describe what the program does, its fees and its risks; no promised outcomes, no hype. The words to avoid are listed in [docs/PRESS-KIT.md](../docs/PRESS-KIT.md#what-not-to-say).
