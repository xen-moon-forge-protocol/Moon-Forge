# Claims register

Every trust, fairness or safety claim Moon Forge makes in public, with where it is made, the evidence anyone can check, and its status in the three tenses of [WORDING.md](WORDING.md): **today** (v2 program, tag `program-2026-10-12`; v2 oracle), **from the switch epoch** (v3 oracle rules, planned for November 2026 with the date announced at least one full epoch ahead; only the upgraded program can publish the first v3 epoch, so it comes no earlier than the first Sunday after the final upgrade; not live) and **after the final upgrade** (earliest 2026-11-11; the freeze earliest 2026-11-25, no later than 2026-12-31). Checked against the repository and the chain on 2026-10-22; the two dated columns re-checked on 2026-10-24 against the source of the final upgrade and the v3 oracle code (items earlier plans named but the final source does not contain are marked PLANNED or removed). This file is a release gate: a claim that is not here, or whose status is not TRUE for the text's tense, does not ship.

Status words: **TRUE** · **CAVEAT** (true with a stated limit that the text must carry) · **OVERSTATED** (true in part; the fix and its owner are named) · **FALSE** · **FUTURE** (true only after the dated event; publishable only as a dated notice) · **RETIRED** (will stop being true at the dated event) · **PLANNED** (decided but not in the program or oracle source yet; never written as part of the dated event until it is).

Evidence shorthand: `constants.rs` = `programs/moon-forge/src/constants.rs`; `tests:N` = `tests/moon-forge.test.ts` line N (the local-validator suite, run by `bash tests/run-local.sh`); `epoch-1` = `frontend/public/epochs/epoch-1.json`; `index` = `frontend/public/epochs/index.json`; `portals` = `deployments/portals.json`. In the two dated columns, `oracle/src/rewards.ts`, `extra.ts`, `flow-v3.ts` and `keeper-v3.ts` are the v3 oracle code and "the final source" is the program source of the final upgrade; both are published for review before the dated event they describe, and a cell that cites them is checked again against the published version.
