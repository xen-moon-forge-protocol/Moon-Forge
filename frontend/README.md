# Moon Forge Frontend

React + Vite site for the Moon Forge Protocol, served by GitHub Pages at
https://xen-moon-forge-protocol.github.io/Moon-Forge/ (Vite `base` = `/Moon-Forge/`).

## Quick start

```bash
npm install
npm run dev      # development server on http://localhost:3000/Moon-Forge/
npm run build    # type-check (tsc) + production build into dist/
```

## Stack

- **React 18** + **React Router** (BrowserRouter with the Vite base path)
- **Vite** and **TypeScript**
- **Tailwind CSS**
- **@solana/web3.js** and **@coral-xyz/anchor** — X1 (SVM) program client, using the IDL in `src/idl/`
- **ethers.js v6** — EVM side (burning XEN through the portals)

## Routes

| Route | Component | Description |
|-------|-----------|-------------|
| `/` | `Home` (in `App.tsx`) | Overview, live pool stats, tiers, fees |
| `/forge` | `TheForge` | Burn XEN on an EVM chain (Base, Optimism, Polygon, BSC and Avalanche live; other chains enabled as their portals are deployed) |
| `/missions` | `MissionControl` | Your epoch leaves: claim, vesting, withdraw vested, eject, Forge Drops |
| `/artifacts` (also `/nft`, `/marketplace`) | `ArtifactsPage` | Forge, recycle and inspect Artifacts (Metaplex Core NFTs) |
| `/games` | `GamesPage` | Game wallet, house games, Jackpot, Duel, Burn Lottery, Be the House |
| `/donate` | `DonationPage` (in `App.tsx`) | Donate to the reward pool, game bankroll or lottery prize vault |
| `/whitepaper` | `WhitepaperPage` | Rules and formulas |
| `/transparency` | `TransparencyPage` | Live config, vaults, lifetime stats, upgrade authority, who can do what |

Any other path renders the home page (GitHub Pages serves `404.html`, a copy of `index.html`).

## Configuration

- EVM portal addresses: `src/lib/constants.ts` (set for Base, Optimism, Polygon, BSC and Avalanche; the other chains stay empty until their portals are deployed).
- Program id, architect address and on-chain helpers: `src/lib/protocol.ts`.
- Published epoch data is read from `public/epochs/`; NFT metadata from `public/nft/` (generated by `scripts/nft-metadata/generate-metadata.mjs`).

## Deployment

`.github/workflows/deploy-frontend.yml` builds the site and publishes it as a GitHub Pages artifact on every push to `main` that touches `frontend/` (and when the weekly oracle workflow commits a new epoch file). It can also be started manually from the Actions tab. Anyone can host their own copy of `dist/` (MIT).
